# Ad Hub

คลังสินค้า affiliate กลาง สำหรับนำโฆษณาสินค้าไปแสดงได้หลายเว็บ เก็บข้อมูลใน Supabase หน้าจัดการเป็นไฟล์ static ขึ้น Netlify ได้เลย
ไม่ผูกกับเว็บขายของเว็บใดเว็บหนึ่ง: แหล่งสินค้า (shopee, lazada, …) ได้จากชื่อเว็บของลิงก์ และกันซ้ำด้วยรหัสสินค้าในลิงก์

## ตอนนี้ทำอะไรได้ (เฟส 1)

- คลังสินค้าแบบการ์ดหรือตาราง ค้นหาชื่อ ร้าน โน้ต (ภาษาไทยได้) กรองตามสถานะ หมวด แหล่ง ช่วงราคา ค่าคอมขั้นต่ำ และเรียงลำดับ
- หมวดหมู่ 2 ชั้น พร้อมจำนวนสินค้าในแต่ละหมวด แต่ละหมวดมี "คำที่ใช้เดาหมวด" สำหรับจัดหมวดอัตโนมัติตอนนำเข้า
- เลือกหลายรายการแล้วย้ายหมวด เปลี่ยนสถานะ หรือลบพร้อมกัน
- แผงแก้ไขด้านข้าง: ชื่อ ลิงก์ รูป (อัปโหลดทับได้) ราคา ค่าคอม ร้าน แท็ก น้ำหนักการสุ่ม ช่วงวันที่แสดง โน้ต
- ปุ่ม **+ เพิ่มสินค้าเอง**: ใส่ลิงก์จากเครือข่ายใดก็ได้ (เช่น AccessTrade) พร้อมชื่อ รูป ราคา ขึ้นเป็น "กำลังแสดง" ทันที ลิงก์ของ AccessTrade (`atth.me`, `*.accesstrade.*`) ได้แหล่งเป็น `accesstrade`
- นำเข้า CSV จาก extension หรือเว็บใดก็ได้: ของใหม่เพิ่มเป็น "รอตรวจ" ของเดิมอัปเดตราคา ค่าคอม ยอดขาย โดยไม่แตะหมวดหรือสถานะที่ตั้งไว้
- ย้ายโฆษณาเดิมจากเว็บที่เก็บไว้ใน `site_meta` (เช่น transfer) เข้าคลังได้ในคลิกเดียว

สถานะสินค้า: รอตรวจ → กำลังแสดง / พักไว้ / หมดอายุ คนทั่วไปเห็นเฉพาะ "กำลังแสดง" ที่อยู่ในช่วงวันที่ตั้งไว้

## นำโฆษณาไปแสดงบนเว็บ (เฟส 3)

- ปุ่ม **เว็บที่แสดงโฆษณา** มุมขวาบน: เพิ่มเว็บ (เช่น คีย์ `transfer`) แล้วเพิ่ม "จุดที่วาง" ของเว็บนั้น
  ต่อจุดตั้งได้: จำนวนโฆษณาต่อหน้า ตำแหน่งในหน้า หมวดที่ให้สุ่ม สินค้าที่ปักหมุด (ขึ้นก่อนเสมอ) ช่องบนการ์ด และเปิด/ปิด
- **ช่องบนการ์ด**: ติ๊กเลือกว่าจะแสดง รูป ชื่อสินค้า คำโปรย ราคา ร้าน (เช่นเอาแค่รูป ชื่อ ร้าน) ป้าย "โฆษณา" แสดงเสมอ
  เว็บที่ฝังเลือกเองได้ด้วย `<div data-adhub="feed" data-show="image,title,shop"></div>` ซึ่งเขียนทับค่าที่ตั้งไว้
  (ใช้กับการ์ดเท่านั้น กล่องรีวิว `data-layout="review"` แสดงครบเสมอ) อัปเดตจากรุ่นก่อน: รัน `supabase/schema.sql` ซ้ำหนึ่งครั้ง
- สินค้าที่ขึ้นคือ "กำลังแสดง" เท่านั้น ที่เหลือสุ่มแบบถ่วงน้ำหนัก (น้ำหนักที่ตั้ง × ค่าคอม × คลิกใน 30 วัน) ไม่ซ้ำกันในหน้าเดียว
- เว็บที่จะแสดงโฆษณาฝังโค้ดนี้ (คัดลอกได้จากหน้าต่างเดียวกัน)
  ```html
  <script src="https://<เว็บ Ad Hub>/ads.js?site=transfer" async></script>
  <div data-adhub="feed"></div>
  <div data-adhub="detail" data-context="ครู"></div>
  ```
  `data-context` คือคำบอกบริบทของหน้า ถ้าตรงกับชื่อหมวดหรือคำของหมวด จะได้สินค้าหมวดนั้นก่อน
- เว็บรีวิว (ระบุสินค้าเจาะจง): สร้างจุดที่วางจุดเดียว เช่น `review` จำนวน 1 แล้วในแต่ละหน้าใส่รหัสสินค้า
  ```html
  <div data-adhub="review" data-product="12" data-layout="review"></div>
  ```
  ถ้าชิ้นนั้นหยุดแสดงแล้ว จะได้ชิ้นอื่นในหมวดเดียวกันแทน คัดลอกโค้ดของแต่ละชิ้นได้จากแผงแก้ไขสินค้า
  `data-layout="review"` วาดเป็นกล่องรีวิว (ดูหัวข้อ "เว็บรีวิว" ด้านล่าง) ถ้าไม่ใส่จะได้การ์ดเล็กแบบโฆษณา
- อยากวาดการ์ดเอง: `const { placement, ads } = await AdHub.load({ placement: "feed", context: "ครู" })`
  ได้ `placement.positions` และ `ads[]` ที่มี `title`, `image`, `price_text`, `shop`, `href` แล้วเรียก `AdHub.observe(กล่อง)`
  ให้นับการแสดง (การ์ดต้องมี `data-adhub-id` และ `data-adhub-placement`) ตัวอย่างเต็มอยู่ใน `tests/ads-e2e.js`
- ลิงก์บนการ์ดไปที่ `/go/<รหัสสินค้า>` ซึ่งนับคลิกแล้วส่งต่อไปลิงก์ affiliate บอทที่มาเปิดดูตัวอย่างลิงก์ไม่ถูกนับ
- การ์ด ตาราง และแผงแก้ไขแสดงจำนวนคลิกและการแสดงย้อนหลัง 30 วัน
- ถ้า Ad Hub ล่ม ads.js ใช้รายการครั้งล่าสุดที่เก็บในเครื่องผู้ชม (ไม่เกิน 7 วัน) ถ้าไม่มีก็แค่ไม่มีโฆษณา หน้าเว็บไม่พัง

## รูปทั้งหมดและรายละเอียดสำหรับทำรีวิว

หน้าข้อเสนอสินค้าในพอร์ทัล affiliate มีแค่รูปปก ราคา และค่าคอม extension จึงเปิดหน้าสินค้าทีละชิ้นในแท็บเบื้องหลัง
แล้วเก็บรูปทั้งหมด (รูปแกลเลอรีก่อน ตามด้วยรูปในคำอธิบายสินค้า ไม่เกิน 30 รูป) คำอธิบายสินค้า แบรนด์ คะแนนรีวิว และข้อมูลจำเพาะ เข้าคลังพร้อมกัน

- ตั้งที่แผงบนหน้า Shopee ช่อง **🖼️ รูปทั้งหมดและรายละเอียด**
  - **เปิดหน้าสินค้า (ไม่ใช้ลิงก์ affiliate)** (ค่าเริ่มต้น): ลองลิงก์ของการ์ดสินค้าก่อน ถ้าหน้านั้นไม่ใช่หน้าสินค้า (เช่นหน้ารายละเอียดข้อเสนอในพอร์ทัล) จะตามลิงก์ "ดูสินค้า" ไปหน้าสินค้าจริง
    ถ้ายังไม่เจอก็ได้แค่รูปปก ไม่เปิดลิงก์ affiliate เด็ดขาด (Shopee จะนับเป็นคลิกในรายงาน affiliate)
  - **ไม่ต้อง**: เร็วเหมือนเดิม รูปปกอย่างเดียว
- ช้าลงชิ้นละประมาณ 3-10 วินาที ระหว่างนั้นจะมีแท็บเปิดขึ้นแล้วปิดเองทีละแท็บ ไม่ต้องกดอะไร
- อ่านจากข้อมูลมาตรฐานของหน้าสินค้า (schema.org Product, og:) และหน้าตาของแกลเลอรีกับหัวข้อ "รายละเอียดสินค้า" / "ข้อมูลจำเพาะ"
  ไม่ได้เขียนไว้เฉพาะ Shopee เว็บอื่นใช้ได้เมื่อเพิ่มชื่อเว็บใน `host_permissions` ของ `extension/manifest.json`
- ส่งสินค้าเดิมซ้ำ: รูปและรายละเอียดใหม่แทนของเดิม ถ้าครั้งนั้นไม่ได้ดึงมา ของเดิมยังอยู่ รูปปกที่ตั้งไว้ไม่ถูกแทน
- แผงแก้ไขสินค้าแสดงรูปทั้งหมด (กดรูปเพื่อใช้เป็นรูปปก) คะแนน ข้อมูลจำเพาะ และแก้รายละเอียดได้
- ปุ่ม ZIP ใน extension ใส่โฟลเดอร์ `review/<ลำดับ>_<ชื่อ>/` ที่มีรูปทั้งหมดและ `รายละเอียด.txt`
- เว็บรีวิวอ่านได้ตรงๆ (เฉพาะสินค้าที่ "กำลังแสดง")
  `GET https://<project>.supabase.co/rest/v1/hub_products?id=eq.12&select=id,title,price_text,images,description,details`
  `details` มี `brand`, `rating`, `rating_count`, `specs` (ชื่อ: ค่า), `detail_url` และ `detail_at` (เวลาที่ดึง)
  ลิงก์ซื้อยังให้ใช้ `/go/<id>` เพื่อนับคลิก

## เว็บรีวิว (เฟส 3.5)

- **กล่องรีวิว** `data-layout="review"`: รูปทั้งหมด (กดรูปเล็กเพื่อเปลี่ยนรูปใหญ่) คะแนน แบรนด์ ยอดขาย ราคา ปุ่ม "ดูราคาล่าสุด / สั่งซื้อ"
  (ไปที่ `/go/` นับคลิก) ข้อความรีวิว ข้อมูลจำเพาะ และรายละเอียดสินค้า พร้อมบรรทัดแจ้งว่าเป็นลิงก์ affiliate
  ปรับสีได้ด้วยตัวแปร CSS `--adhub-accent`, `--adhub-fg`, `--adhub-bg`, `--adhub-border`, `--adhub-muted`
- **หน้ารีวิวตัวอย่าง** `https://<เว็บ Ad Hub>/review.html?site=<คีย์เว็บ>&id=<รหัสสินค้า>` (จุดที่วางชื่อ `review` หรือใส่ `&placement=...`)
  ได้กล่องรีวิวและ "สินค้าที่คล้ายกัน" ในหมวดเดียวกัน ชื่อหน้าเป็นชื่อสินค้า คัดลอก `web/review.html` ไปเป็นแม่แบบของเว็บรีวิวได้
- **วาดเอง**: `await AdHub.load({ placement: "review", product: 12, full: true })` ได้ `ads[]` ที่มี `images`, `description`, `review`,
  `details` (`brand`, `rating`, `rating_count`, `specs`) เพิ่มจากปกติ หรือ `AdHub.render(กล่อง, ads, { layout: "review" })`
- **เขียนรีวิวในแผงแก้ไขสินค้า** ช่อง "รีวิว" มี 2 ปุ่ม แก้ข้อความได้ก่อนกดบันทึก
  - **เขียนด้วย AI**: ให้ AI เขียนจากข้อมูลจริงที่บันทึกไว้ (รายละเอียด สเปก คะแนน) สั่งไว้ว่าห้ามแต่งข้อมูลและห้ามอ้างว่าใช้เอง
    ถ้า AI ใช้ไม่ได้ (ยังไม่ตั้งคีย์ โทเคน/เครดิตหมด เรียกถี่เกิน) จะสุ่มแบบป้ายยาให้แทนพร้อมบอกเหตุผล
  - **สุ่มแบบป้ายยา**: ได้ทันที ไม่เสียโทเคน สุ่มประโยคจากชุดข้อความ (`web/js/review-writer.js`) ใส่ข้อมูลจริงของสินค้า
  - ควรอ่านทุกรีวิวก่อนบันทึก AI อาจเขียนผิด และรีวิวที่คนอ่านแล้วได้ประโยชน์จริงช่วยให้ติดอันดับค้นหาดีกว่าข้อความสุ่ม

## API สำหรับเว็บหรือแอปอื่น

ทุกอย่างเรียกผ่าน HTTP ของ Supabase ได้ตรงๆ ไม่ต้องใช้ ads.js (เช่นเว็บที่สร้างหน้าตอน build หรือแอปมือถือ)
ทุกคำขอใส่ header `apikey: <Publishable key>` และ `Content-Type: application/json`
(ถ้าใช้ anon key แบบเก่าที่ขึ้นต้นด้วย `eyJ` ใส่ `Authorization: Bearer <anon key>` ด้วย)

**ดึงโฆษณา** `POST https://<project>.supabase.co/rest/v1/rpc/hub_ads`

| ช่อง | ความหมาย |
|---|---|
| `p_site` | คีย์เว็บ เช่น `"transfer"` (ต้องมี) |
| `p_placement` | คีย์จุดที่วาง เช่น `"feed"` (ต้องมี) |
| `p_products` | รหัสสินค้าที่ต้องการ เช่น `[12]` ขึ้นก่อนตามลำดับ |
| `p_context` | คำบอกบริบทของหน้า เช่น `"จอคอม"` |
| `p_count` | จำนวนที่ต้องการ (ไม่ใส่ = ตามที่ตั้งไว้ในจุดที่วาง สูงสุด 24) |
| `p_exclude` | รหัสสินค้าที่หน้าแสดงไปแล้ว ไม่ต้องการซ้ำ |

```json
{"p_site": "review", "p_placement": "review", "p_products": [12]}
```
ได้กลับมา
```json
{"placement": {"key": "review", "slots": 1, "positions": []},
 "ads": [{"id": 12, "title": "...", "caption": "คำโปรย (อาจว่าง)", "price": 320, "price_text": "฿320", "sold_text": "...", "shop": "...", "source": "shopee", "image_url": "https://..."}]}
```
เว็บหรือจุดที่วางที่ไม่มีหรือปิดอยู่ได้ `{"placement": null, "ads": []}`

**ลิงก์บนการ์ด** ต้องชี้ไปที่ `https://<project>.supabase.co/functions/v1/go/<id>?s=<คีย์เว็บ>&p=<คีย์จุดที่วาง>`
ไม่มีลิงก์ affiliate ตรงในผลลัพธ์ เพื่อให้ทุกคลิกถูกนับ

**ข้อมูลรีวิว** `POST .../rest/v1/rpc/hub_product_info` ด้วย `{"p_ids": [12]}` (ไม่เกิน 24 รหัส ใช้รหัสที่ได้จาก `hub_ads`)
ได้ `[{"id": 12, "images": [...], "description": "...", "review": "...", "details": {"brand", "rating", "rating_count", "specs"}}]`
เฉพาะสินค้าที่ "กำลังแสดง" ไม่มีรูปทั้งหมดจะได้รูปปกแทน

**นับการแสดง** (ไม่บังคับ) `POST .../rest/v1/rpc/hub_log_views` ด้วย `{"p_site": "...", "p_placement": "...", "p_ids": [12, 40]}` ไม่เกิน 24 รหัสต่อครั้ง

## ติดตั้งครั้งแรก

1. **ฐานข้อมูล** เปิดโปรเจกต์ Supabase เดิม (ตัวเดียวกับ transfer) > SQL Editor > วางไฟล์ `supabase/schema.sql` ทั้งไฟล์ > Run
   ตารางทั้งหมดขึ้นต้นด้วย `hub_` ไม่ชนกับตารางของ transfer รันซ้ำได้ ไม่ทำให้ข้อมูลหาย
2. **บัญชีแอดมิน** Authentication > Users > Add user > Create new user (ใส่อีเมลและรหัสผ่าน ติ๊ก Auto Confirm)
   แล้วรันใน SQL Editor (เปลี่ยนอีเมลเป็นของคุณ)
   ```sql
   insert into hub_admins (user_id, email)
   select id, email from auth.users where email = 'you@example.com';
   ```
3. **ค่าเชื่อมต่อ** Project Settings > API Keys คัดลอก Project URL และ Publishable key (หรือ anon key) ใส่ใน `web/config.js`
   ห้ามใส่ Secret key ในไฟล์นี้ เพราะไฟล์นี้ทุกคนเปิดอ่านได้
4. **ขึ้นเว็บ** Netlify > Add new site > Import from GitHub > เลือก repo นี้ ค่าอื่นไม่ต้องแก้ (`netlify.toml` ตั้งให้แล้ว)
   หรือทดสอบในเครื่อง: `python3 -m http.server 8080` แล้วเปิด http://localhost:8080/web/
5. ล็อกอิน > นำเข้าสินค้า > "ย้ายโฆษณาเดิมจาก transfer" เพื่อเอาโฆษณาที่มีอยู่เข้าคลัง
6. **ลิงก์นับคลิก `/go/`** Supabase > Edge Functions > Deploy a new function > Via Editor
   ตั้งชื่อ `go` วางไฟล์ `supabase/functions/go/index.ts` ทั้งไฟล์ > Deploy
   แล้วเข้าหน้าตั้งค่าของฟังก์ชัน ปิดตัวเลือกตรวจ JWT (ชื่อประมาณ "Verify JWT") > Save เพราะคนกดโฆษณาไม่ได้ล็อกอิน
   (ถ้าใช้ Supabase CLI: `supabase functions deploy go` ค่า verify_jwt ตั้งไว้ใน `supabase/config.toml` แล้ว)
   ไม่บังคับ: ตั้ง Secret `HUB_FALLBACK_URL` เป็นหน้าเว็บที่จะพาไปเมื่อสินค้าถูกลบแล้ว
   ทดสอบ: เปิด `https://<project>.supabase.co/functions/v1/go/<รหัสสินค้า>` ต้องเด้งไปหน้า Shopee
7. ใน Ad Hub กด **เว็บที่แสดงโฆษณา** > เพิ่มเว็บ > เพิ่มจุดที่วาง แล้วคัดลอกโค้ดฝังไปใส่ในเว็บนั้น
8. **ปุ่มเขียนรีวิวด้วย AI** (ไม่บังคับ ไม่ทำก็ใช้แบบสุ่มได้) Edge Functions > Deploy a new function > Via Editor
   ตั้งชื่อ `review` วางไฟล์ `supabase/functions/review/index.ts` > Deploy (เปิด Verify JWT ไว้ตามเดิม มีแต่แอดมินที่ใช้ได้)
   แล้วกลับมาที่ Ad Hub กดปุ่ม **ตั้งค่า AI** เลือกเจ้า วางคีย์ เลือกรุ่น > บันทึก
   (คีย์เก็บในตาราง `hub_settings` อ่านได้เฉพาะแอดมิน หน้าเว็บเห็นแค่ 4 ตัวท้าย)

   หรือจะตั้งที่ Edge Functions > Secrets แทนก็ได้ (ใช้เมื่อยังไม่ได้ตั้งคีย์ในหน้า ตั้งค่า AI)

   | เจ้า | `AI_PROVIDER` | `AI_API_KEY` | `AI_MODEL` | `AI_BASE_URL` |
   |---|---|---|---|---|
   | Claude (ค่าเริ่มต้น) | `anthropic` หรือไม่ใส่ | คีย์จาก console.anthropic.com | ไม่ใส่ = `claude-opus-5-5` (ถูกกว่า: `claude-haiku-5-5`) | ไม่ใส่ |
   | OpenAI | `openai` | คีย์ OpenAI | ชื่อรุ่นที่ใช้ | ไม่ใส่ |
   | Gemini | `openai` | คีย์ Google AI Studio | เช่น `gemini-2.5-flash` | `https://generativelanguage.googleapis.com/v1beta/openai` |
   | DeepSeek | `openai` | คีย์ DeepSeek | `deepseek-chat` | `https://api.deepseek.com` |
   | OpenRouter (หลายเจ้าในคีย์เดียว) | `openai` | คีย์ OpenRouter | ชื่อรุ่นตาม OpenRouter | `https://openrouter.ai/api/v1` |

   เจ้าอื่นที่รองรับรูปแบบ OpenAI (`/chat/completions`) ใช้แบบเดียวกัน เปลี่ยนเจ้าได้ทุกเมื่อจากหน้า ตั้งค่า AI ไม่ต้องแก้โค้ด

ถ้าเคยติดตั้งเฟส 1-2 แล้ว ให้รัน `supabase/schema.sql` ซ้ำอีกครั้งหนึ่ง (ไม่ทำให้ข้อมูลหาย) แล้วทำข้อ 6-7

ถ้าติดตั้งไปแล้วก่อนมีการปิด/ลดการแสดงทั้งหมวด: รัน `supabase/schema.sql` ซ้ำ (เพิ่มคอลัมน์ `ad_level` ของหมวด)

ถ้าติดตั้งไปแล้วก่อนมีปุ่ม สถิติ: รัน `supabase/schema.sql` ซ้ำ (เพิ่มฟังก์ชัน `hub_dashboard`)

ถ้าติดตั้งไปแล้วก่อนมีปุ่ม ตั้งค่า AI: รัน `supabase/schema.sql` ซ้ำ (เพิ่มตาราง `hub_settings`) แล้ว Deploy ฟังก์ชัน `review` ใหม่ด้วยไฟล์ล่าสุด

ถ้าติดตั้งไปแล้วก่อนมีคำโปรย: รัน `supabase/schema.sql` ซ้ำ (เพิ่มคอลัมน์ `caption`)

ถ้าติดตั้งไปแล้วก่อนเฟส 3.5: รัน `supabase/schema.sql` ซ้ำ (เพิ่มคอลัมน์ `review` และฟังก์ชัน `hub_product_info`) แล้วทำข้อ 8 ถ้าจะใช้ AI

ถ้าติดตั้งไปแล้วก่อนมีรูปทั้งหมดและรายละเอียด: รัน `supabase/schema.sql` ซ้ำ (เพิ่มคอลัมน์ `images`, `description`, `details`)
แล้วโหลด extension ใหม่ที่ `chrome://extensions` (กดรีโหลด) เพราะต้องได้สิทธิ์ `scripting` เพิ่ม และรีเฟรชหน้า Shopee

อยากได้ลิงก์สั้นเป็น `https://<เว็บ Ad Hub>/go/<id>` (ไม่บังคับ): เพิ่มใน `netlify.toml`
```toml
[[redirects]]
  from = "/go/*"
  to = "https://<project>.supabase.co/functions/v1/go/:splat"
  status = 200
```
แล้วใส่ `goUrl: "https://<เว็บ Ad Hub>/go"` ใน `web/config.js`

## แอป Android ดูจำนวนคลิก (`android/`)

แอปอ่านอย่างเดียว ดูจำนวนคลิกโฆษณาที่ Ad Hub นับเอง (ผ่านลิงก์ `/go`) ไม่ต้องพึ่งตัวเลขจาก Shopee Affiliate

- ดาวน์โหลด: หน้า **Releases** ของ repo นี้ → `clicks-app` → `adhub-clicks.apk` (GitHub Actions build ให้ทุกครั้งที่แก้ `android/`)
  ติดตั้งบนมือถือ (อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้เบราว์เซอร์ครั้งแรก) รุ่นใหม่ติดตั้งทับรุ่นเก่าได้เลย
- เปิดครั้งแรกใส่ Project URL และ Publishable key (ค่าเดียวกับ `web/config.js`) แล้วล็อกอินด้วยบัญชีแอดมินเดิม
  แอปไม่รับ Secret key / service_role และเห็นข้อมูลได้เฉพาะแอดมิน (ตาม RLS ของ `hub_events`) ไม่ต้องแก้ฐานข้อมูลเพิ่ม
- ดูได้: ยอดคลิกวันนี้ / เมื่อวาน / 7 / 30 / 90 วัน เทียบช่วงก่อนหน้า กราฟรายวันหรือรายชั่วโมง
  แยกตามสินค้า (แตะดูรายวันของชิ้นนั้น พร้อมรหัสสินค้า Shopee ไว้เทียบรายงาน) และตามเว็บ/ตำแหน่ง วันที่ตามเวลาไทย
- นับทุกคลิก รวมคนเดิมกดซ้ำ (ไม่เก็บตัวตนผู้ชม) จึงอาจมากกว่าตัวเลขของ Shopee ที่ตัดคลิกซ้ำออก
- หน้าจอเป็น HTML/JS ใน `android/app/src/main/assets/` ทดสอบในเบราว์เซอร์ได้: `node tests/clicks-app-e2e.js`
- กุญแจเซ็นแอป `android/app/adhub-clicks.keystore` อยู่ใน repo (private) เพื่อให้ทุกรอบเซ็นเหมือนกัน ถ้าเปิด repo เป็นสาธารณะควรย้ายไปเป็น secret
