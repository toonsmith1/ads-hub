# 🧵 ShopiThread TH — Shopee Affiliate ไทย & เครื่องมือสร้างแคปชัน Threads

ส่วนขยาย Google Chrome (Manifest V3) ครบวงจรสำหรับนายหน้า **Shopee Affiliate ประเทศไทย (`shopee.co.th`)**:
- ⚡ **ดึงข้อมูลสินค้า & ลิงก์สั้นอัตโนมัติ**: กดปุ่ม "รับลิงก์" อัตโนมัติเพื่อดึงลิงก์สั้น `s.shopee.co.th` พร้อมรูปภาพสินค้าความละเอียดสูง (HD) ราคา (฿) ค่าคอมมิชชัน และยอดขาย
- 📊 **แดชบอร์ดจัดการสินค้า & CSV**: บันทึกข้อมูลสินค้าไว้ในเครื่อง ค้นหา แก้ไข นำเข้าและส่งออกไฟล์ `.CSV` (รองรับภาษาไทยใน Excel 100%), `.TXT` และแพ็กเกจรูปภาพ `.ZIP`
- 🧵 **สร้างแคปชันป้ายยา Threads ภาษาไทย**: มาพร้อมเทมเพลตป้ายยาภาษาไทย ระบบสุ่มข้อความ Spintax และคลังแฮชแท็กยอดนิยมในไทย (`#ป้ายยาShopee`, `#รีวิวShopee`, `#ของมันต้องมี`)
- ✍️ **ส่งข้อความไปที่แท็บ Threads**: เปิดเว็บ Threads.net และวางแคปชันลงในกล่องข้อความให้อัตโนมัติโดยไม่กดโพสต์เอง (ปลอดภัย ไม่เสี่ยงโดนแบน)

---

## 🚀 วิธีติดตั้งลงใน Google Chrome

1. ดาวน์โหลดโปรเจกต์นี้เป็นไฟล์ ZIP ([คลิกดาวน์โหลดที่นี่](https://github.com/toonsmith1/shopithread/archive/refs/heads/main.zip)) แล้วแตกไฟล์ลงในโฟลเดอร์บนเครื่องคอมพิวเตอร์ของคุณ
2. เปิดเบราว์เซอร์ Google Chrome แล้วไปที่ `chrome://extensions`
3. เปิดสวิตช์ **โหมดนักพัฒนาซอฟต์แวร์ (Developer mode)** ที่มุมขวาบน
4. คลิกปุ่ม **โหลดส่วนขยายที่ยังไม่ได้แพ็ก (Load unpacked)** แล้วเลือกโฟลเดอร์ที่คุณแตกไฟล์ไว้

## 💡 วิธีใช้งาน

1. เข้าสู่ระบบบัญชี Shopee Affiliate ประเทศไทยที่หน้า [affiliate.shopee.co.th/offer/product_offer](https://affiliate.shopee.co.th/offer/product_offer)
2. คลิกปุ่มลอยสีส้ม **📦 เครื่องมือ Affiliate** ที่มุมขวาล่างของหน้าจอ
3. เลือกจำนวนหน้าที่ต้องการดึงข้อมูล (1–10 หน้า) แล้วคลิก:
   - **💾 บันทึกลงแดชบอร์ด & CSV**: เพื่อเก็บข้อมูลสินค้าไว้จัดการและสร้างแคปชัน Threads
   - **⚡ สร้างไฟล์ ZIP & ดาวน์โหลดรูปภาพ**: เพื่อดาวน์โหลดรูปภาพ HD ทั้งหมดพร้อมไฟล์ CSV/TXT ทันที
4. คลิก **📊 เปิดแดชบอร์ดสินค้า & CSV** เพื่อจัดการสินค้าและสร้างแคปชันป้ายยาบน Threads
